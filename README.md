# SALIM HOSTING v2 — সেটআপ গাইড (মাল্টি-ইউজার + অ্যাডমিন)

এটা একটা সম্পূর্ণ ফাংশনাল self-hosted প্যানেল, যেখান থেকে আপনি নিজের যেকোনো Python স্ক্রিপ্ট/গেম বট/প্রজেক্ট আপলোড করে বা GitHub থেকে ডিপ্লয় করে চালাতে, বন্ধ করতে ও লগ দেখতে পারবেন। v2-তে এখন **একাধিক ইউজার + অ্যাডমিন সিস্টেম** যোগ করা হয়েছে।

## নতুন কী আছে (v2.1 — জরুরি ফিক্স)

- **Dockerfile যোগ করা হয়েছে**: আগে `nixpacks.toml` দিয়ে python3/git ইনস্টল করানোর চেষ্টা হচ্ছিল, কিন্তু Railway-তে অনেক সময় এটা ঠিকমতো কাজ করছিল না — ফলে `python3`/`git` কমান্ড না পাওয়ায় স্ক্রিপ্ট রান বা GitHub ডিপ্লয় ফেইল করছিল (`spawn python3 ENOENT`, `spawn git ENOENT`)। এখন repo-তে একটা `Dockerfile` আছে, যেটাতে সরাসরি Node.js + Python3 + pip + git ইনস্টল করা থাকে — Railway `Dockerfile` পেলে সেটাকেই ব্যবহার করে, তাই এটা নিশ্চিত কাজ করবে।
- **ZIP এক্সট্র্যাক্ট ফিচার**: এখন Files ট্যাবে কোনো `.zip` ফাইল আপলোড করলে তার পাশে **📦 Extract** বাটন দেখাবে — চাপলেই সেটা একই ফোল্ডারে extract হয়ে যাবে (একটা নতুন ফোল্ডারে, zip-এর নামে)।
- **ফাইল আপলোডের ENOTDIR এরর ফিক্স**: ফাইল মুভ করার লজিক আরও সরল ও নির্ভরযোগ্য করা হয়েছে (copy তারপর delete), যাতে Volume-মাউন্টেড ফোল্ডারেও এরর ছাড়া কাজ করে।

## নতুন কী আছে (v2)

- **মাল্টি-ইউজার সিস্টেম**: একাধিক ইউজার তৈরি করা যাবে, প্রত্যেকের **নিজস্ব আলাদা workspace** (ফাইল) এবং **নিজস্ব আলাদা প্রসেস** (স্ক্রিপ্ট রান) — একজনের ফাইল/প্রসেস আরেকজন দেখতে বা ছুঁতে পারবে না।
- **অ্যাডমিন রোল**: অ্যাডমিন নতুন ইউজার তৈরি, ডিলিট, পাসওয়ার্ড রিসেট করতে পারবে, এবং **"View As"** বাটন দিয়ে যেকোনো ইউজারের ড্যাশবোর্ডে গিয়ে তার হয়ে ফাইল/প্রসেস কন্ট্রোল করতে পারবে।
- **প্রতি ইউজারের জন্য আলাদা লিংক**: `https://<your-domain>/u/<username>` — এটা একই সার্ভারের একটা vanity/bookmark URL (নিচে বিস্তারিত ব্যাখ্যা আছে)।
- **নিরাপত্তা ফিক্স** (আগের ভার্সনে যেসব সমস্যা ছিল, সব ঠিক করা হয়েছে):
  - পাসওয়ার্ড এখন **bcrypt দিয়ে হ্যাশ করে** সেভ হয় (আগে প্লেইনটেক্সট ছিল)
  - Session secret এখন **র‍্যান্ডমলি জেনারেট ও পার্সিস্ট** হয় (আগে কোডে হার্ডকোডেড ছিল)
  - ফাইল-পাথ ভ্যালিডেশন আরও কড়া করা হয়েছে (path-traversal বাগ ফিক্স)
  - Private GitHub টোকেন এখন কনসোল লগে **মাস্ক করে** দেখানো হয় (আগে পুরো URL-সহ টোকেন লগে লেখা হতো)
  - লগইনে বেসিক **rate-limit** যোগ করা হয়েছে (এক মিনিটে ১০ বারের বেশি ভুল চেষ্টা হলে ব্লক)
  - আপলোড ফাইলের সাইজ **50MB ক্যাপ** এখন সার্ভার-সাইডেও এনফোর্স হয়

## ইউজার সিস্টেম কীভাবে কাজ করে

- প্রতিটা ইউজারের (admin বা user) নিজস্ব আলাদা **workspace ফোল্ডার** থাকে (`workspace/<username>/`) — নিজের আপলোড করা ফাইল, স্ক্রিপ্ট, শুধু সেই ইউজারই দেখতে পারবে।
- প্রতিটা ইউজারের নিজস্ব আলাদা **রানিং প্রসেস** থাকে — একজনের বট চালু থাকলে আরেকজনের প্রসেসের সাথে মিক্স হবে না, আলাদা START/STOP/Console।
- **admin** রোলের ইউজার অতিরিক্ত একটা **👑 Admin** ট্যাব দেখবে যেখান থেকে:
  - নতুন ইউজার তৈরি করা যাবে (username, password, role বেছে)
  - প্রতিটা ইউজারের লিংক কপি করা যাবে
  - যেকোনো ইউজারের পাসওয়ার্ড রিসেট করা যাবে
  - যেকোনো ইউজারকে ডিলিট করা যাবে
  - **"View As"** বাটনে ক্লিক করে সেই ইউজারের ড্যাশবোর্ডে গিয়ে তার হয়ে সব কন্ট্রোল করা যাবে (ফাইল আপলোড, স্ক্রিপ্ট স্টার্ট/স্টপ ইত্যাদি) — উপরে একটা কমলা ব্যানারে "Admin viewing as ..." দেখাবে, আর "Back to my account" বাটনে ফিরে আসা যাবে।
- **user** রোলের ইউজার শুধু নিজের workspace/প্রসেস/প্রোফাইল দেখতে ও কন্ট্রোল করতে পারবে; অ্যাডমিন ট্যাব দেখবে না।

## "প্রতি ইউজারের জন্য আলাদা লিংক" — গুরুত্বপূর্ণ ব্যাখ্যা

⚠️ Railway (বা যেকোনো হোস্টিং প্ল্যাটফর্ম) নিজে থেকে প্রতি ইউজারের জন্য আলাদা ডোমেইন/সাবডোমেইন **তৈরি করে দেয় না**। আপনি একটাই পাবলিক ডোমেইন পাবেন (যেমন `salim-hosting.up.railway.app`)। এই অ্যাপ সেই একই ডোমেইনের নিচে প্রতি ইউজারের জন্য একটা আলাদা **পাথ** বানায়:

```
https://salim-hosting.up.railway.app/u/SALIM
https://salim-hosting.up.railway.app/u/rahim
https://salim-hosting.up.railway.app/u/karim
```

এই লিংকটা শুধু **সুবিধার জন্য** — এতে ঢুকলে সেই ইউজারনেম লগইন বক্সে আগে থেকেই বসানো থাকবে (বুকমার্ক করে রাখা সহজ হয়)। কিন্তু **আসল অ্যাক্সেস কন্ট্রোল হয় পাসওয়ার্ড ও সেশন দিয়ে**, লিংক দিয়ে না — অর্থাৎ `/u/rahim` লিংকে গেলেই কেউ rahim-এর ড্যাশবোর্ড দেখতে পারবে না, তাকে rahim-এর সঠিক পাসওয়ার্ড দিয়ে লগইন করতেই হবে (অথবা অ্যাডমিন হলে "View As" দিয়ে ঢুকতে পারবে)।

## কীভাবে ব্যবহার করবেন

- **Admin ট্যাব** থেকে নতুন ইউজার তৈরি করুন, তাকে তার username/password এবং তার লিংক (`/u/username`) দিন
- সেই ইউজার নিজের লিংকে গিয়ে নিজের ইউজারনেম/পাসওয়ার্ড দিয়ে লগইন করবে
- **Files** ট্যাব থেকে `.py` ফাইল, `requirements.txt` আপলোড করুন, অথবা **GitHub** ট্যাব থেকে রিপো ডিপ্লয় করুন
- **Startup** ট্যাবে মেইন ফাইলের নাম সেট করুন
- **START** চাপুন — এটা প্রথমে `requirements.txt` থেকে প্যাকেজ ইনস্টল করবে, তারপর স্ক্রিপ্ট চালাবে
- **Console** ট্যাবে লাইভ লগ দেখা যাবে

## গুরুত্বপূর্ণ নোট

- এই প্যানেল দিয়ে আপনি **যেকোনো বৈধ Python প্রজেক্ট, গেম বট (Discord/Telegram official API দিয়ে), অটোমেশন স্ক্রিপ্ট, ওয়েব অ্যাপ** ইত্যাদি হোস্ট করতে পারবেন।
- সরাসরি কারো একাউন্টের ইউজারনেম/পাসওয়ার্ড ব্যবহার করে কোনো প্ল্যাটফর্মে (Facebook ইত্যাদি) অটোমেটেড অ্যাকশন চালানো — এই ধরনের ফিচার ইচ্ছাকৃতভাবে এখানে রাখা হয়নি, কারণ এটা প্ল্যাটফর্মের নিয়ম ভঙ্গ করে।
- পাবলিক সার্ভারে ডিপ্লয় করলে অবশ্যই ডিফল্ট পাসওয়ার্ড বদলে নেবেন এবং HTTPS/ফায়ারওয়াল ব্যবহার করবেন।
- অ্যাডমিন অ্যাকাউন্ট কমপক্ষে ১টা সবসময় থাকতেই হবে — শেষ অ্যাডমিনকে ডিলিট বা ডিমোট করা যাবে না (কোডে এটা আটকানো আছে)।

## Railway-তে ডিপ্লয় করার নিয়ম

1. এই ফোল্ডারটা একটা GitHub রিপোতে পুশ করুন (`.gitignore`-এ থাকায় `node_modules`, `data/users.json`, `workspace/` আপলোড হবে না — এগুলো ইউজার-স্পেসিফিক ডেটা, রিপোতে থাকা উচিত না)। **⚠️ রিপোর রুটেই যেন `package.json`, `Dockerfile`, `server.js` সরাসরি থাকে — এক্সট্রা কোনো প্যারেন্ট ফোল্ডারের ভিতরে না।** GitHub-এ আপলোড করার সময় zip থেকে বের হওয়া `salim-hosting-v2` ফোল্ডারের **ভিতরের সব ফাইল** রিপোর রুটে রাখবেন, পুরো ফোল্ডারটাকে একটা সাবফোল্ডার হিসেবে না রেখে।
2. [railway.app](https://railway.app) এ গিয়ে **New Project → Deploy from GitHub repo** সিলেক্ট করুন।
3. Railway `Dockerfile` দেখে সেটা দিয়েই বিল্ড করবে (Node.js + Python3 + pip + git সব একসাথে ইনস্টল হবে) — এখানে আলাদা করে কিছু সেট করার দরকার নেই।
4. **Settings → Networking** থেকে **Generate Domain** করে একটা পাবলিক URL নিন (এটাই আপনার সবার শেয়ার্ড বেস ডোমেইন, যার নিচে `/u/username` লিংকগুলো কাজ করবে)।
5. ⚠️ **জরুরি — ডেটা পার্সিস্টেন্স:** Railway-এর ফাইলসিস্টেম ডিফল্টভাবে *ephemeral* (রিডিপ্লয় করলে ফাইল মুছে যায়)। ইউজার লিস্ট ও সবার আপলোড করা স্ক্রিপ্ট ধরে রাখতে Railway-তে **Volume** যোগ করুন এবং সেটাকে `/app/workspace` এবং `/app/data` পাথে মাউন্ট করুন (Project → Service → **Volumes** ট্যাব)। এটা ছাড়া প্রতিবার রিডিপ্লয়ে সব ইউজার ও ফাইল মুছে ডিফল্ট `SALIM`/`changeme123`-এ ফিরে যাবে।
6. প্রথমবার ডিপ্লয় হওয়ার পর সাইটে গিয়ে ডিফল্ট `SALIM` / `changeme123` দিয়ে লগইন করে সাথে সাথে **My Profile** থেকে পাসওয়ার্ড বদলে নিন, তারপর **Admin** ট্যাব থেকে বাকি ইউজার তৈরি করুন।
7. Railway নিজে থেকেই `PORT` এনভায়রনমেন্ট ভ্যারিয়েবল সেট করে দেয় — কোডে সেটা আগে থেকেই হ্যান্ডেল করা আছে।

**যদি এখনো python3/git ENOENT এরর দেখায়:** Railway ডিপ্লয়মেন্ট লগে (Build লগ, Deploy লগ না) দেখুন `Dockerfile` ব্যবহার হচ্ছে কিনা লেখা আছে কিনা। যদি এখনো `nixpacks` ব্যবহার হচ্ছে দেখায়, Service **Settings → Build** থেকে Builder ম্যানুয়ালি **Dockerfile** সিলেক্ট করে দিন এবং redeploy করুন।
